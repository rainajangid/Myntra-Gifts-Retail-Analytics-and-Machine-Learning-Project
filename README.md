Project Overview

This project solves a real-world retail analytics problem using data science and machine learning. It uses historical online transaction data from **Myntra Gifts Ltd.**, a fictional UK-based giftware company, to predict customer purchase revenue, extract strategic insights, and support data-driven business decisions.


Motivation

Retail companies operate in a fast-paced, seasonal environment. Optimizing sales, pricing, and inventory requires predictive insights from past transactions. This project builds a complete ML pipeline — from raw data to explainable model output — demonstrating how machine learning can empower smart retail operations.



Problem Statement

How can Myntra Gifts Ltd. use historical online retail data to forecast revenue, optimize inventory, and tailor marketing strategies to improve profitability and efficiency?


Dataset Source

- File: `Introduction to ML project- Online Retail.xlsx`
- Transactions from 2009 to 2011
- ~540,000 rows × 8 columns
- Fields:
  - `InvoiceNo`, `StockCode`, `Description`, `Quantity`, `UnitPrice`
  - `InvoiceDate`, `CustomerID`, `Country`
